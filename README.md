# TechParts — магазин комплектующих для ПК и телефонов

Рабочий сайт на Java (без Maven и сторонних библиотек): каталог, корзина, оформление заказа,
личный кабинет, статьи, рекламные места и админ-панель.

## Запуск
Windows: дважды щёлкните `run.bat` (нужен JDK 11+). Linux/Mac: `./run.sh`.
Сайт откроется в браузере: http://localhost:8080/

## Вход администратора
Логин `admin`, пароль `admin123`. Смените пароль в Личный кабинет > Безопасность.

## Что есть
- Магазин: каталог с поиском и сортировкой, карточка товара, корзина, доставка, оплата, рассрочка.
- Личный кабинет: статус клиента, скидки, история заказов, оценка обслуживания, профиль, смена пароля.
- Админ-панель (`#/admin`): статьи с фото, видео (файл MP4/WEBM или YouTube) и галереей,
  товары, реклама, заказы, пользователи, медиатека, статистика.
- Реклама: баннер под шапкой, блок сбоку, рекламный пост в ленте статей, всплывающее окно,
  нижняя полоса, реклама перед видео (пропуск через 5 с). Считаются показы и клики.
- Бизнес-правила (условия if-else, &&, ||, !, switch, вложенные if) находятся в `src/Logic.java`:
  скидки, акции по дням недели, доставка, оплата, рассрочка, оценка риска заказа, калькуляторы.

## Данные
Папка `data/` создаётся при первом запуске: JSON-файлы таблиц и `data/uploads/` с загруженными фото и видео.
Чтобы сбросить сайт, остановите его и удалите папку `data`.
